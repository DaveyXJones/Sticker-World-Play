# Sticker Worlds

A sticker book where cabinets, fridges, windows and planets open into whole new scenes, so you can zoom in forever.

This is the copy that plays without a Claude account. Open it in Safari on an iPad or iPhone, tap Share, then **Add to Home Screen**, and always play from that icon: the book is saved on the device, inside the app.

These files are built from a private repository (`sh sticker-worlds/build.sh` makes `sticker-worlds/site/`). Don't edit them here: changes belong in the source, and the next build replaces these.
