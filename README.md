# Sticker Worlds

A sticker book where cabinets, fridges, windows and planets open into whole new scenes, so you can zoom in forever.

This is the copy that plays without a Claude account, on iPhone, iPad and Android. Put it on the Home Screen and always play from that icon: the book is saved on the device, inside the app.

- iPhone or iPad: open it in Safari, tap Share, then **Add to Home Screen**.
- Android: open it in Chrome, tap the ⋮ menu, then **Add to Home screen** (or **Install app**).

These files are built from a private repository (`sh sticker-worlds/build.sh` makes `sticker-worlds/site/`). Don't edit them here: changes belong in the source, and the next build replaces these.
